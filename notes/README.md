# Hotel CMS — заметки проекта

Специализированная CMS для управления гостиницей на Ruby on Rails.

## Разделы

- [[decisions|Журнал решений]] — принятые архитектурные и продуктовые решения (ADR)
- [[tasks|Задачи]] — текущие задачи и статусы
- [[improvements|Улучшения функционала]] — дорожная карта доработок
- [[handbook|Хендбук]] — команды, структура проекта, нюансы работы

## Шаблоны

- [[Templates/note]] — обычная заметка
- [[Templates/decision]] — решение (ADR)
- [[Templates/daily]] — дневная заметка

## Как вести заметки

- Формат — Obsidian: YAML frontmatter, `[[wikilinks]]`, `#теги`
- Язык — русский
- Значимые решения → заносить в `decisions.md`, дату и контекст — обязательно
- Отчёты о работе в проекте → дневные заметки в `daily/`
- Вложения → `notes/attachments/`
